📋 Estructura del Curso

Total: 5 evaluaciones → 100% de progreso
Cada evaluación se completa para desbloquear la siguiente

Evaluaciones:

  • Evaluación Tema 1: Conceptos Básicos (20%)
  • Evaluación Tema 2: Medición y Equipos (20%)
  • Evaluación Tema 3: Cálculos y Proyecciones (20%)
  • Evaluación Tema 4: Aplicaciones Civil 3D (20%)
  • Evaluación Final: Examen Integrador (20% - Desbloqueada después de Tema 4)
🔓 Desbloqueo automático:
La evaluación final se desbloquea automáticamente cuando el estudiante completa la evaluación del Tema 4 con 70%+

📖 Cómo Funciona

1️⃣ Para el Estudiante:

  • ✓ Accede a: /sesiones/panel-evaluaciones.html
  • ✓ Ve todas las evaluaciones disponibles
  • ✓ Completa las evaluaciones en orden (primero Tema 1, 2, 3, 4)
  • ✓ Cuando completa Tema 4, se desbloquea automáticamente la Final
  • ✓ El progreso sube 20% con cada evaluación completada
  • ✓ Al completar la Final, llega a 100%

2️⃣ Progreso del Curso:

📊 0% → Inicial
📊 20% → Después de completar Tema 1
📊 40% → Después de completar Tema 2
📊 60% → Después de completar Tema 3
📊 80% → Después de completar Tema 4
📊 100% → Después de completar Final (completa el curso ✅)

3️⃣ Evaluaciones Bloqueadas:

Solo la "Evaluación Final" comienza bloqueada 🔒
Se desbloquea automáticamente cuando se completa la evaluación del Tema 4
